Saving a document on every keystroke. Each save carries the whole document (a PUT), so only the latest version matters: concurrency: 'queue-latest' keeps the saves in order and skips the versions overtaken while a save is in flight. Two calls at most: the one in flight and the latest. A keystroke replaces the waiting call, whose mutate() rejects with 'Replaced', never sent. With a debounce, a save also waits for a pause in typing. Source: queue-latest · debounce

Save on every keystroke

Send the whole document: a replaced call is never sent, so a delta would be lost. Don't roll it back either, although wasNeverSent() is true: the newer call carries a more recent state. Typed slowly, every keystroke is sent, since nothing is in flight: see the debounce below. More in the recipes.

Save once typing pauses

Each call waits 500 ms after its mutate(), and a newer call replaces it meanwhile. Unlike a debounce before mutate(), the call is pending from the first keystroke: isPending() shows the edit isn't saved yet. The wait overlaps the save in flight, so a slow request adds no extra delay.
