Saving a document on every keystroke. Each save carries the whole document (a PUT), so only the latest version matters: concurrency: 'queue-latest' keeps the saves in order and skips the versions overtaken while a save is in flight. Two calls at most: the one in flight and the latest. A keystroke replaces the waiting call, whose mutate() rejects with 'Replaced', never sent. Source

Send the whole document: a replaced call is never sent, so a delta would be lost. Don't roll it back either, although wasNeverSent() is true: the newer call carries a more recent state. A debounce still cuts the calls made while nothing is in flight. More in the recipes.
