What a second mutate() does while a call is in flight. By default it runs in parallel. concurrency: 'queue' waits for the previous call, so writes reach the server in order. concurrency: 'queue-latest' waits too, but keeps only the latest waiting call. concurrency: 'drop' rejects it at once.
