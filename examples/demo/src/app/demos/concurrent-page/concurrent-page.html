The concurrency option

What a second mutate() does while a call is in flight:

'parallel'
Runs at once (the default, above).
'queue'
Waits for the previous call: move an item to the top.
'queue-latest'
Waits, replacing the call already waiting: autosave.
'drop'
Rejected at once, never sent: pay.
mutationQueue()
Waits for the calls of every mutation sharing the queue: rename, then delete.
{{ '{' }} queue, key {{ '}' }}
Waits for the calls with the same key: save per document.
A replaced or dropped call rejects with an AbortError ('Replaced', 'Dropped') and runs no callback; wasNeverSent(error) is true for it. In every mode, the state signals follow the mutation's latest call, and pendingInputs() lists the queued calls too.
