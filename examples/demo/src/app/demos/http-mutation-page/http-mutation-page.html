httpMutation(), from @ngsignal/mutation/http, is the counterpart of httpResource(): request returns a request description ({{ '{' }} method, url, body {{ '}' }}) and the library sends it through HttpClient. That's why it also exposes statusCode, headers, uploadProgress and downloadProgress. A fake HttpInterceptorFn stands in for the server, with artificial delays. Source
