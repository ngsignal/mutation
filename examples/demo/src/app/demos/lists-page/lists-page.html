One mutation shared by every item of a list, called once per item. pendingInputs() lists the inputs of the calls still in flight: a spinner on each item being written, and pendingInputs().length for the progress of a bulk action. When the order of the writes matters, as when reordering a list, concurrency: 'queue' sends them one at a time. Source: seats · move to top

Lock seats

Each column has its own fake server. By hand, the list of seats in flight is updated in three places: before the call, on success and on error; a branch that forgets it leaves a seat "Locking…" forever. A seat leaves pendingInputs() when its call settles, whatever the outcome, and reset() or destroy empty it. input() only follows the latest call, and isPending() only says whether any call is in flight. A bulk endpoint that takes an array is a single call: its whole array is one entry.

Move an item to the top

Each click runs both mutations, one fake server each. In parallel, Charlie's request ends last, so the server puts Charlie first although Alpha was clicked last; queued, Alpha's request only leaves once Charlie's has settled. The queue orders the writes of this mutation only. Several mutations writing the same data, such as a rename then a delete, share a mutationQueue(): see Rename, then delete.
