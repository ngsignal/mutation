One mutation shared by every item of a list, called once per item. pendingInputs() lists the inputs of the calls still in flight: a spinner on each item being written, and pendingInputs().length for the progress of a bulk action made of one mutate() per item. A bulk endpoint that takes an array is a single call: its whole array is one entry. Reordering a list needs its writes to reach the server in order: concurrency: 'queue'.
