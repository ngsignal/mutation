rxMutation(), from @ngsignal/mutation/rxjs-interop, is the counterpart of rxResource(): mutationFn returns an Observable, typically an existing service method such as http.post(). The last emitted value resolves the call once the Observable completes; reset() or destroying the component unsubscribes. Source
