Saving several documents: the saves of one document must stay in order, but needn't wait for another document's. {{ '{' }} queue, key {{ '}' }} gives each document its own line in a mutationQueue(); a call without a key, such as Delete all, waits for every document. Source

A key orders the calls, it doesn't skip any: every save of A reaches the server. To send only the latest version of each document, use one 'queue-latest' mutation per document (see Autosave). Pitfalls of shared queues in the recipes.
