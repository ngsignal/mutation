status() and the flags

status() is 'idle', 'pending', 'success' or 'error', and each flag is one of them as a boolean. The submit button above reads isPending():

status
{{ createUser.status() }}
isIdle / isPending / isSuccess / isError
{{ createUser.isIdle() }} / {{ createUser.isPending() }} / {{ createUser.isSuccess() }} / {{ createUser.isError() }}

hasValue()

A type guard: inside the @if, value() is User, not User | undefined, so no ?. or !.

@if (createUser.hasValue()) {
{{ createUser.value().name }} #{{ createUser.value().id }}

The same guard works in computed() (last created: {{ lastCreatedName() ?? '—' }}). The card stays after an error: only a new success or reset() replaces value().

Each @case narrows it: snap.value is a User in 'success', snap.error an ApiError in 'error'.
